# 🎣 Phishing Awareness Training Module
### CodeAlpha Cyber Security Internship — Task 2

---

## 📌 Overview

An interactive, browser-based **Phishing Awareness Training Module** built for IT and technical staff. This module educates users on recognising, understanding, and defending against phishing attacks through structured lessons, real-world examples, and an interactive quiz.

---

## 🖥️ Live Demo

Open `phishing_awareness_training.html` directly in any browser — no server or dependencies required.

---

## 📚 Module Contents

The training is divided into **5 interactive sections**:

| Section | Topic |
|--------|-------|
| 01 | **What Is Phishing?** — Definition, why IT staff are targeted, attack kill chain |
| 02 | **Attack Types** — Spear Phishing, Whaling, BEC, Vishing, AiTM, Quishing, and more |
| 03 | **Live Email Example** — Annotated interactive phishing email with hover-reveal red flags |
| 04 | **Technical Defenses** — DMARC/SPF/DKIM, FIDO2 vs TOTP, Zero Trust, IR playbook |
| 05 | **Knowledge Quiz** — 5 scenario-based questions with instant feedback and scoring |
